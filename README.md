# my-apps

내가 클로드 코드로 만드는 개인 앱들을 모아두는 곳. 각 앱은 폴더 하나로 독립되어 있어요.

> 아들이 쓰는 **축구 앱(gio-football)** 은 따로 쓰던 걸 그대로 유지하려고 **별도 저장소**에 두었어요. 여기엔 없습니다.

## 앱 목록

| 앱 | 폴더 | 설명 | 열기 |
|----|------|------|------|
| 💰 나의 가계부 | [`budget/`](budget/) | 매달 반복되는 수입·지출을 한 번 등록하면 매월 자동 반영. 이번 달 잔액·고정/변동·카테고리 차트를 한눈에. | `budget/index.html` |
| 📈 주식 종목 보고서 | [`stock/`](stock/) | 관심 종목의 실시간 시세 + 차트 지표 자동 계산 + 증권사 리포트를 날짜별로 쌓아 컨센서스·주가를 함께 추적하는 나만의 리서치 저널. | `stock/index.html` |
| 🗣️ DualTalk AI (우리집 영어회화) | [`english/`](english/) | 아빠는 비즈니스 미팅 15종 + MBTI 친구 모드, 지오는 일상회화 15종 + 패턴·스티커 — 듣기·따라 말하기(음성인식 채점)·역할극, API 키를 넣으면 AI 롤플레잉·힌트·리포트까지. | `english/index.html` |

## 특징

- 설치 필요 없음 — `index.html`을 브라우저로 열면 바로 사용
- 인터넷 없어도 동작 (데이터는 사용 기기에 저장)
- 휴대폰: 크롬에서 열고 "홈 화면에 추가" 하면 앱처럼 사용
- 데이터 백업: 각 앱의 설정 화면에서 내보내기/가져오기(JSON)
